## 🔬 Current R&D

### [Sector's Finance Agent](https://github.com/rizmdhn/sector_finance_agent)
A multi-agent platform that acts as a finance analyst for the Indonesia Stock Exchange (IDX).

- A **Chief orchestrator** routes each question to four specialist agents (research, portfolio risk, market events, and an independent reviewer that checks the others' work)
- **Every figure is dated and traceable**: each reply shows which agents, tools, tokens and API credits it used
- **Asks before spending**: an approval card estimates cost before any uncached API call, and the model can't approve its own spending
- **Guardrails + evals**: no investment advice, no forecasts, rate limits, and LLM-as-judge compliance checks

`Python` `FastAPI` `Strands Agents` `PostgreSQL` `Valkey` `React` `TypeScript` `Arize Phoenix` `Docker`
